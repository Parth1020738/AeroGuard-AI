# Data Model & Storage Specification — AeroGuard AI

## 1. Storage Engine
- **Engine:** Client-Side Browser `localStorage` (Web Storage API) + Strict In-Memory TypeScript Domain State.
- **Root Storage Key:** `aeroguard_state_v1`
- **Hosting / Boundary:** 100% Client-Side. No remote relational or NoSQL database is required or utilized.
- **Persistence Strategy:** Automatic write-on-mutate with JSON serialization and defensive deserialization guards.

---

## 2. Naming Conventions
- **Interfaces & Types:** `PascalCase` (e.g., `HouseholdProfile`, `SmogActionItem`, `PersistedAppState`).
- **Object Properties & Variables:** `camelCase` (e.g., `aqiValue`, `hasPurifier`, `pm25ReductionPercent`).
- **Enums & Constants:** `UPPER_SNAKE_CASE` (e.g., `AQI_SEVERITY_TIERS`, `STORAGE_KEY`).
- **File Names:** `camelCase` for utilities/types (`airQuality.ts`), `PascalCase` for React components (`ActionCard.tsx`).

---

## 3. Data Entities & Schemas (`src/types/airQuality.ts`)

### 1. `HouseholdProfile`
Captures environmental severity and household lifestyle parameters to tailor AI prompts and deterministic fallbacks.

```typescript
export type CommuteMode = 'walking' | 'twoWheeler' | 'publicTransit' | 'car';
export type CleanAirGear = 'none' | 'n95Masks' | 'diyBoxFan' | 'hepaPurifier';
export type CookingHeatingFuel = 'lpg' | 'pipedGas' | 'induction' | 'biomassChulha' | 'kerosene';
export type HomeType = 'apartment' | 'standalone' | 'highRise';

export interface HouseholdProfile {
  city: string;                         // Max 50 chars, sanitized
  outdoorAqi: number;                   // 0 to 999
  vulnerableGroups: {
    hasChildren: boolean;               // Under 12
    hasSeniors: boolean;                // Over 65
    hasRespiratorySensitivity: boolean; // Asthma, COPD, bronchitis
    hasPregnancy: boolean;              // Maternal vulnerability
  };
  homeType: HomeType;
  commuteMode: CommuteMode;
  cleanAirGear: CleanAirGear;
  cookingFuel: CookingHeatingFuel;
  updatedAt: string;                    // ISO 8601 timestamp
}
```

### 2. `SmogActionItem`
Individual actionable recommendation generated by Gemini or the fallback engine.

```typescript
export type ActionCategory = 'routines' | 'indoorHacks' | 'sustainableAlternatives';
export type CostLevel = 'free' | 'low' | 'moderate';
export type DifficultyLevel = 'easy' | 'medium';

export interface SmogActionItem {
  id: string;                           // Unique slug, e.g., "diy-cr-box-purifier"
  title: string;                        // Brief human-readable title
  category: ActionCategory;             // Category tab
  steps: string[];                      // Concise 2-3 step instructions
  costLevel: CostLevel;                 // Budget indication
  difficulty: DifficultyLevel;          // Implementation friction
  scientificRationale: string;          // "Why This Works" explanation
  impactEstimates: {
    dailyPm25ReductionUgm3: number;     // e.g., 42 (micrograms per m3 reduced)
    pm25ReductionPercent: number;       // e.g., 28 (%)
    weeklyCo2SavedKg: number;           // e.g., 3.5 (kg CO2 prevented)
  };
  enabled: boolean;                     // Selected state in choice simulator
}
```

### 3. `VentilationWindow`
Hourly atmospheric advisory based on winter thermal inversion modeling.

```typescript
export type VentilationRiskLevel = 'lockdown' | 'caution' | 'safe';

export interface VentilationWindow {
  hourRange: string;                    // e.g., "12:30 PM - 02:00 PM"
  riskLevel: VentilationRiskLevel;      // lockdown | caution | safe
  title: string;                        // "Midday Solar Ventilation Window"
  instruction: string;                  // "Open cross-windows for 15 mins to clear CO2"
  ambientAqiTrend: 'peaking' | 'rising' | 'moderate' | 'falling';
}
```

### 4. `AirQualityPlan`
The complete generated advice payload returned by Gemini 2.5 Flash or `fallbackSmogPlan.ts`.

```typescript
export interface AirQualityPlan {
  planId: string;                       // Unique generated ID
  city: string;
  baselineOutdoorAqi: number;
  severityLabel: 'Good' | 'Moderate' | 'Poor' | 'Very Poor' | 'Severe';
  generatedAt: string;                  // ISO 8601 timestamp
  isOfflineFallback: boolean;           // Flag indicating fallback engine origin
  summaryHeadline: string;              // High-level 1-sentence guidance
  actions: SmogActionItem[];            // Categorized action list
  ventilationTimeline: VentilationWindow[]; // 24-hour horizon timeline
  communityAdvisoryText: string;        // Text formatted for school/society notices
}
```

### 5. `PersistedAppState`
Root schema serialized inside `localStorage['aeroguard_state_v1']`.

```typescript
export interface PersistedAppState {
  version: 1;                           // Schema version for future migrations
  profile: HouseholdProfile;
  activePlan: AirQualityPlan | null;
  selectedActionIds: string[];          // IDs of user-enabled choices
  hasCompletedOnboarding: boolean;
  lastSyncTimestamp: number;
}
```

## 5. Validation Rules
- **City Name:** String between 2 and 50 characters. Automatically sanitized against control codes. Defaults to "Delhi NCR" if blank.
- **Outdoor AQI:** Number clamped between `0` and `999`. Non-numeric inputs default to `180`.
- **Action IDs:** Unique alphanumeric slugs matching `/^[a-z0-9-]+$/`.
- **Actions Count:** Generated plans must contain between 6 and 12 total actions (at least 2 per category).
- **Ventilation Timeline:** Must contain between 3 and 5 time windows spanning morning, midday, evening, and night.
- **Selected Action IDs:** Must only contain IDs currently existing within `activePlan.actions`.

---

## 6. Migration & Reset Rules
1. **Schema Versioning:** The `version` field in `PersistedAppState` tracks breaking changes.
2. **Version Incompatibility:** If stored state contains a `version !== 1`, or if JSON parsing fails due to data corruption, the storage layer catches the exception, clears `localStorage['aeroguard_state_v1']`, and initializes with `DEFAULT_PERSISTED_STATE`.
3. **Manual Reset:** A prominent "Reset Profile & Plan" button is available in the UI header to clear state on demand.

---

## 7. Sensitive Data Policy
- **Zero Personally Identifiable Information (PII):** AeroGuard AI never asks for, captures, or persists user names, email addresses, exact home addresses, phone numbers, or IP coordinates.
- **Local Isolation:** Data never leaves the browser except as an anonymized, sanitized prompt payload sent directly to the official Google Gemini API endpoint over TLS.
